# Fabric looking glass — `fabric_api_*`

The `fabric-api node` and `fabric-api gateway` commands expose these metrics on their separate endpoints. The node uses the instrumentation registry; the gateway also serves controller-runtime metrics. The `certsync`, `janitor` and `query` commands do not serve a metrics endpoint. See [scraping and ports](README.md#where-the-metrics-come-from) and [Fabric API operations](../fabric-api/operations.md#observability).

Histograms also expose the standard Prometheus bucket, sum and count series. Vector metrics may be absent until a label value is observed. Requests, targets, node names and project identifiers are not metric labels. Index metrics are registered when the search index is active; node clock metrics require probe permits. Gateway limiter, clock, key and stream gauges require aggregate budgets.

## Node sidecar

| Metric                                                       | Type      | Meaning                                                                                                                                                                                 |
| ------------------------------------------------------------ | --------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `fabric_api_node_requests_total`                             | counter   | Execute calls by query type and outcome (OK or the error code). Labels: `type`, `outcome`.                                                                                              |
| `fabric_api_node_request_duration_seconds`                   | histogram | Execute call duration by query type, including queueing. Labels: `type`.                                                                                                                |
| `fabric_api_node_response_bytes`                             | histogram | Serialized Execute response size by query type. Labels: `type`.                                                                                                                         |
| `fabric_api_node_truncated_responses_total`                  | counter   | Responses shaped down to budget, by query type. Labels: `type`.                                                                                                                         |
| `fabric_api_node_in_flight_requests`                         | gauge     | Execute calls currently running or queued.                                                                                                                                              |
| `fabric_api_node_duplicate_requests_total`                   | counter   | Execute calls answered from the duplicate-suppression cache.                                                                                                                            |
| `fabric_api_node_duplicate_cache_entries`                    | gauge     | Entries in the duplicate-suppression cache.                                                                                                                                             |
| `fabric_api_node_diagnostics_available`                      | gauge     | 1 when FRR is reachable at a supported version and credentials are loaded.                                                                                                              |
| `fabric_api_node_frr_info`                                   | gauge     | FRR version last read from bgpd, and whether it is supported. Labels: `version`, `supported`.                                                                                           |
| `fabric_api_node_expensive_breaker_open`                     | gauge     | 1 while expensive searches are suspended after an uncertain timed-out scan.                                                                                                             |
| `fabric_api_node_probe_packets_total`                        | counter   | ICMP probe packets sent.                                                                                                                                                                |
| `fabric_api_certificate_expiry_timestamp_seconds`            | gauge     | NotAfter of the loaded mTLS certificate: the gateway's client certificate or the node's serving certificate.                                                                            |
| `fabric_api_credentials_loaded`                              | gauge     | 1 when valid mTLS credentials are loaded.                                                                                                                                               |
| `fabric_api_node_identity_refreshes_total`                   | counter   | Reads of FRR version, router ID and ASN, by outcome. Labels: `outcome`.                                                                                                                 |
| `fabric_api_node_permits_total`                              | counter   | Probe permits the node verified, by outcome: accepted, or why it refused one (invalid, malformed, mismatch, expired, starting, clock, lease, epoch, replayed, full). Labels: `outcome`. |
| `fabric_api_node_clock_synchronized`                         | gauge     | 1 while the kernel reports its clock synchronised within the permit bound; probe permits are refused otherwise.                                                                         |
| `fabric_api_node_bmp_route_messages_total`                   | counter   | BMP Loc-RIB route monitoring messages applied to the search index.                                                                                                                      |
| `fabric_api_node_search_index_routes`                        | gauge     | Prefixes in the search index. Labels: `afi`.                                                                                                                                            |
| `fabric_api_node_search_index_attribute_sets`                | gauge     | Distinct path attribute sets the search index holds.                                                                                                                                    |
| `fabric_api_node_search_index_overflow_total`                | counter   | Route announcements dropped because the search index was at its route ceiling.                                                                                                          |
| `fabric_api_node_search_index_synced`                        | gauge     | 1 when the search index holds bgpd's full table and follows it over BMP.                                                                                                                |
| `fabric_api_node_search_index_last_update_timestamp_seconds` | gauge     | When the search index last applied a route change.                                                                                                                                      |

## Cell gateway

| Metric                                                | Type      | Meaning                                                                                                                                                                                                                                                   |
| ----------------------------------------------------- | --------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `fabric_api_gateway_service_requests_total`           | counter   | Looking Glass service requests that ended on this replica, by operation and reason: the terminal coverage reason of a delivered stream, the refusal's reason before its snapshot, or DeliveryFailed when its stream broke. Labels: `operation`, `reason`. |
| `fabric_api_gateway_service_router_outcomes_total`    | counter   | Routers of Looking Glass service requests, by operation and outcome: OK, a failure reason, or the reason a router was omitted from the request. Labels: `operation`, `outcome`.                                                                           |
| `fabric_api_gateway_service_request_duration_seconds` | histogram | Time from the leader's receipt of a Looking Glass service request to the end of its stream, for requests whose snapshot was delivered. Labels: `operation`.                                                                                               |
| `fabric_api_gateway_admission_refusals_total`         | counter   | Work the cell's aggregate admission refused, by traffic class (service, operator, fabricquery), limiter scope (cell, project, destination, queue) and reason (Throttled, QueueFull, LimiterUnavailable). Labels: `class`, `scope`, `reason`.              |
| `fabric_api_gateway_probe_packets_charged_total`      | counter   | Worst-case probe packets charged to the cell's budgets, by traffic class. Labels: `class`.                                                                                                                                                                |
| `fabric_api_gateway_queries_total`                    | counter   | FabricQuery executions finished, by query type and terminal reason. Labels: `type`, `reason`.                                                                                                                                                             |
| `fabric_api_gateway_node_outcomes_total`              | counter   | Per-node outcomes of executions: OK, an error code, or an omission reason. Labels: `outcome`.                                                                                                                                                             |
| `fabric_api_gateway_node_rpc_duration_seconds`        | histogram | Execute RPC duration to a node, by query type and outcome code. Labels: `type`, `code`.                                                                                                                                                                   |
| `fabric_api_gateway_queue_wait_seconds`               | histogram | Time node RPCs waited for a cell execution slot.                                                                                                                                                                                                          |
| `fabric_api_gateway_status_writes_total`              | counter   | FabricQuery status writes by kind (start, terminal) and outcome (ok, conflict, error). Labels: `kind`, `outcome`.                                                                                                                                         |
| `fabric_api_gateway_status_bytes`                     | histogram | Serialized size of terminal FabricQuery objects.                                                                                                                                                                                                          |
| `fabric_api_gateway_truncated_results_total`          | counter   | Terminal results shaped down to the object byte budget.                                                                                                                                                                                                   |
| `fabric_api_gateway_stage_latency_seconds`            | histogram | Latency of each stage of a query's life as seen by the cell: receipt (creation to first reconcile), execution (start marker to last node answer), completion (creation to terminal status). Labels: `stage`.                                              |
| `fabric_api_gateway_executions_in_flight`             | gauge     | FabricQuery executions running on this gateway.                                                                                                                                                                                                           |
| `fabric_api_gateway_stale_objects`                    | gauge     | FabricQuery objects in this cell past their expiration (or completion) plus retention and cleanup grace, which neither the federation nor the janitor has deleted.                                                                                        |
| `fabric_api_certificate_expiry_timestamp_seconds`     | gauge     | NotAfter of the loaded mTLS certificate: the gateway's client certificate or the node's serving certificate.                                                                                                                                              |
| `fabric_api_credentials_loaded`                       | gauge     | 1 when valid mTLS credentials are loaded.                                                                                                                                                                                                                 |
| `fabric_api_gateway_queue_depth`                      | gauge     | Node RPCs waiting for a cell execution slot.                                                                                                                                                                                                              |
| `fabric_api_gateway_service_enabled`                  | gauge     | 1 while this replica's service switch lets the Looking Glass service execute.                                                                                                                                                                             |
| `fabric_api_gateway_limiter_state`                    | gauge     | 1 for the aggregate limiter's current state: ready, recovering (in its recovery hold) or unavailable (not the leader, or unable to confirm the election or the clock). Labels: `state`.                                                                   |
| `fabric_api_gateway_limiter_keys`                     | gauge     | Keys the aggregate limiter holds, by kind: project (project and principal buckets), destination (host and prefix buckets) and attempt (live attempt keys). Labels: `kind`.                                                                                |
| `fabric_api_gateway_service_streams`                  | gauge     | Live Looking Glass service streams the leader holds, queued and draining ones included.                                                                                                                                                                   |
| `fabric_api_gateway_clock_synchronized`               | gauge     | 1 while the kernel reports its clock synchronised within the limiter's bound; the limiter admits nothing otherwise.                                                                                                                                       |
